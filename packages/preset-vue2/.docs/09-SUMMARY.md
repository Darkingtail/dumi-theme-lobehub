## 2. 技术收获

### 2.1 dumi 生态理解

通过本项目，深入理解了 dumi 的核心机制：

- **Preset 机制**：如何打包一组插件为可复用的预设
- **Tech Stack**：如何扩展 dumi 支持新的技术栈
- **Atom Parser**：如何从源码提取组件元数据
- **Webpack 集成**：如何与 dumi 的构建系统协作

### 2.2 Vue 2 编译原理

深入了解 Vue 2 的编译流程：

- **SFC 解析**：template/script/style 的分离与处理
- **模板编译**：template → render 函数的转换过程
- **JSX 转换**：Babel 如何处理 Vue 2 JSX 语法
- **Scoped Styles**：样式隔离的实现原理

### 2.3 浏览器端编译

掌握了浏览器端代码编译的技术方案：

- **Babel Standalone**：在浏览器中使用 Babel 转换代码
- **CDN 资源加载**：动态加载外部编译器
- **缓存策略**：LRU 缓存优化编译性能
- **错误处理**：优雅处理编译和运行时错误

## 3. 经验教训

### 3.1 好的决策

1. **复用 dumi 基础设施**：大幅降低开发成本
2. **选择 vue-docgen-api**：成熟稳定，社区支持好
3. **自研 PropType 增强**：弥补了 vue-docgen-api 的不足
4. **模块化设计**：代码结构清晰，便于维护

### 3.2 踩坑记录

1. **Babel 版本兼容**：不同版本间 API 有差异，需锁定版本
2. **Scoped Styles 优先级**：选择器处理需要考虑各种边界情况
3. **JSX 区分逻辑**：简单的特征匹配可能误判，需要多维度判断
4. **CDN 加载时序**：需要正确处理异步加载和依赖关系

### 3.3 待改进项

1. **TypeScript 支持**：可考虑集成 TS Language Service 获得更完整的类型支持
2. **测试覆盖**：单元测试覆盖率需要提升
3. **文档完善**：可添加更多示例和使用场景
