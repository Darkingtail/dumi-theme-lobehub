⏺ Vue 2 TSX/JSX Live Editing 开发总结

  目标

  在 dumi-theme-lobehub 的 preset-vue2 中实现 Vue 2 TSX/JSX 文件的 Live
  Editing 功能。

  遇到的技术难点及解决方案

  问题 1: 路径限制过严

  现象: Demo 文件在 /vue2demo/ 目录，但 jsx.ts 的 isSupported 检查的是
  /vue2/ 或 /vue2-，导致 TSX 文件不被识别。

  解决方案: 移除路径限制，让所有 .jsx/.tsx 文件都被 Vue 2 JSX tech stack
  处理。

  // Before: 路径限制
  isSupported(node, lang) {
    return ['jsx', 'tsx'].includes(lang) &&
           (node.path.includes('/vue2/') || node.path.includes('/vue2-'));
  }

  // After: 无路径限制
  isSupported(node, lang) {
    return ['jsx', 'tsx'].includes(lang);
  }

  ---
  问题 2: h is not defined (Composition API)

  现象: 使用 defineComponent + setup() 返回 JSX 时报错 ReferenceError: h is 
  not defined。

  原因: @vue/babel-preset-jsx 默认 injectH: true，会注入：
  const h = this.$createElement;
  但在 setup() 函数中 this 是 undefined，无法访问 $createElement。

  解决方案: 设置 injectH: false，让用户显式 import { h } from 'vue'：

  // node.ts
  'vue2-jsx': [require.resolve('@vue/babel-preset-jsx'), { injectH: false }]

  ---
  问题 3: Webpack 规则未生效

  现象: 修改了 node.ts 后，编译时仍然报错。

  原因: Webpack 配置中的 vue2-jsx-tsx 规则有 resourceQuery 限制，但实际的
  demo 文件导入没有带查询参数。

  发现过程:
  - dumi 技术栈导入 demo 时会添加 ?techStack=vue2-tsx 查询参数
  - 但 Webpack 规则需要同时有 injectH: false 配置

  ---
  问题 4: Vue JSX 插件解析错误

  现象:
  TypeError: Cannot read properties of undefined (reading 'toLowerCase')
  at parseAttributeJSXAttribute

  原因: Babel presets 按逆序执行。配置为：
  presets: [
    ...babelInUmi.options.presets,  // 包含 React JSX 转换
    [tsPresetPath, ...],            // TypeScript
    ['@vue/babel-preset-jsx', ...]  // Vue JSX
  ]
  执行顺序: Vue JSX → TypeScript → umi presets

  问题在于:
  1. Vue JSX 先执行，但此时代码还有 TypeScript 类型注解
  2. umi 的 presets 可能包含 React JSX 转换，与 Vue JSX 冲突

  解决方案:
  1. 移除 umi presets（避免 React JSX 冲突）
  2. 调整顺序让 TypeScript 先运行（在数组最后）

  // config.ts - 最终配置
  config.module
    .rule('vue2-jsx-tsx')
    .test(/\.(jsx|tsx)$/)
    .resourceQuery(/techStack=vue2-tsx/)
    .use('babel-loader')
    .loader(babelInUmi.loader)
    .options({
      // 不继承 umi presets，避免 React JSX 转换冲突
      presets: [
        // Vue JSX 第二个执行（转换 JSX 为 h() 调用）
        [require.resolve('@vue/babel-preset-jsx'), { injectH: false }],
        // TypeScript 第一个执行（移除类型注解）
        [tsPresetPath, { allExtensions: true, isTSX: true,
  onlyRemoveTypeImports: true }],
      ],
      plugins: babelInUmi.options.plugins || [],
    });

  ---
  核心原理图解

  ┌─────────────────────────────────────────────────────────────────┐
  │                    Babel 转换流程 (逆序执行)                      │
  ├─────────────────────────────────────────────────────────────────┤
  │                                                                 │
  │  源代码 (TSX + TypeScript)                                      │
  │  ─────────────────────────                                      │
  │  import { defineComponent, h } from 'vue';                      │
  │  interface Props { name: string; }                              │
  │  export default defineComponent({                               │
  │    setup() {                                                    │
  │      return () => <div>Hello</div>;                             │
  │    }                                                            │
  │  });                                                            │
  │                                                                 │
  │         ↓ Step 1: TypeScript Preset (最后定义，最先执行)          │
  │                                                                 │
  │  中间代码 (JSX, 无类型)                                          │
  │  ────────────────────                                           │
  │  import { defineComponent, h } from 'vue';                      │
  │  export default defineComponent({                               │
  │    setup() {                                                    │
  │      return () => <div>Hello</div>;                             │
  │    }                                                            │
  │  });                                                            │
  │                                                                 │
  │         ↓ Step 2: Vue JSX Preset (injectH: false)               │
  │                                                                 │
  │  最终代码 (纯 JavaScript)                                        │
  │  ───────────────────────                                        │
  │  import { defineComponent, h } from 'vue';                      │
  │  export default defineComponent({                               │
  │    setup() {                                                    │
  │      return () => h('div', null, 'Hello');                      │
  │    }                                                            │
  │  });                                                            │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

  ---
  关键配置总结

  | 配置项                   | 值                    | 作用
                                      |
  |-----------------------|----------------------|--------------------------
  ------------------------------|
  | injectH               | false                | 不自动注入 const h = 
  this.$createElement，适配 Composition API |
  | allExtensions         | true                 | TypeScript
  处理所有文件扩展名                                   |
  | isTSX                 | true                 | 启用 TSX 支持
                                    |
  | onlyRemoveTypeImports | true                 |
  只移除类型导入，保留值导入                                          |
  | resourceQuery         | /techStack=vue2-tsx/ | 只处理 dumi 标记的 Vue 2
  demo 文件                             |
