⏺ The package has been rebuilt with the Vue.extend() fix.

  Summary of the fix:

  The issue was that Vue.extend() returns a constructor function, and when
  React's setComponent(component) receives a function, it treats it as a
  state updater and calls it. This caused Vue's constructor to be invoked
  without new, leading to this being undefined and the _init error.

  The fix:
  // Before: directly used the export
  const __sfc__ = Vue.extend({...})

  // After: extract options from constructor
  const __sfc___raw = Vue.extend({...})
  var __sfc__ = typeof __sfc___raw === 'function' && __sfc___raw.options
    ? __sfc___raw.options  // Extract plain options object
    : __sfc___raw;         // Use directly if already an object

  问题分析

  1. Vue 2 的 h 函数签名不同

  Vue 2 的 h 函数（即 $createElement）只在组件实例的 render 函数内部可用：
  // Vue 2 正确用法
  export default {
    render(h) {  // h 是参数，由 Vue 注入
      return h('div', { class: 'foo' }, 'hello')
    }
  }

  2. Vue 2.7 的 Composition API h 不同

  Vue 2.7 虽然有 import { h } from 'vue'，但它的工作方式与 Vue 3
  不完全相同，且在 setup 返回渲染函数时有特殊要求。

  3. 组件解析问题

  React JSX 直接传递组件构造函数：h(Card, props)，但 Vue 2
  需要组件在特定上下文中被解析。

  4. @vue/babel-preset-jsx 做了很多特殊处理

  - 自动注入 h 到 render 函数作用域
  - 处理 v-model、v-on、slot 等指令
  - 正确处理组件注册和解析
